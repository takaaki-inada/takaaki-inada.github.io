## 関連リンク


- [Migrating our Messages API to Rust](https://www.anthropic.com/research/migrating-api-to-rust)  


Anthropic社が、生成AIサービスの基盤であるMessages APIをPythonからRustへ移行した際の技術的アプローチと検証手法について解説しています。2024年初頭から2026年秋にかけてAPIトラフィックが約1,800倍に急増したことを受け、CPU使用率の削減とパフォーマンス向上のために移行が行われました。

大規模なライブシステムの移行において最大の課題となるのはコードの生成ではなく、新旧システムの挙動が完全に一致しているかを検証する「正確性の担保」です。移行期間中もPython版のAPIは機能追加やモデル更新により変更され続け、さらにClaudeの出力が非決定的（同じ入力でも回答が異なる）であるため、単に新旧の出力を比較するだけでは不十分でした。また、ユーザーのプライバシー保護の観点からリクエスト内容を直接読むこともできない制約がありました。

これらの課題を解決するため、同社は「本番環境のMessages API自体を検証器（オーラクル）として活用するシャドーフライング」という手法を導入しました。主なアプローチは以下の通りです。

- **チェックポイント機能**: リクエストの受付、設定解決、プロンプト構築といった処理の各ステップにおける結果を比較し、新旧コードのどこで差異が生じたかを特定しました。
- **フィンガープリンティング**: 差異が生じた位置やデータサイズの差からバグの「指紋（フィンガープリント）」を生成し、同じ種類のバグを自動的にグルーピングしてトリアージを行いました。
- **検証ループの構築**:
  - **インナーループ**: クラウドサンドボックス環境でAIエージェントが高速に仮説検証と修正を行い、ローカルの高速な入力・出力チェックで動作確認を実施。
  - - **アウターループ**: 本番のシャドー環境におけるトラフィックを用いて修正の効果を検証。
  - **メモリーループ**: 人間によるコードレビューでの指摘や修正履歴をエージェントの記憶（CLAUDE.mdやメモリー）に蓄積し、同じ間違いを防ぐルールとして後続のエージェントに学習させました。

人間は「何が正しいか」の判断やコードレビューに集中し、AIエージェントが自律的に差異の特定と修正を繰り返す体制をとることで、サービスを停止することなく、また機能開発を凍結することもなく移行を完了させました。結果として、Rust版APIはリクエストあたりのCPU使用率を約70%削減し、初回トークン到達までのレイテンシ（median time to first token）を約20%短縮することに成功しています。本記事は、生成AIを活用した大規模リファクタリングや自律型エージェントによる開発フローの設計における重要な実践知見を提供しています。

引用元: https://www.anthropic.com/research/migrating-api-to-rust


- [How to Run NVIDIA Cosmos 3 on Local AI Devices Using Hugging Face Diffusers](https://developer.nvidia.com/blog/how-to-run-nvidia-cosmos-3-on-local-ai-devices-using-hugging-face-diffusers/)  


この記事では、NVIDIAが提供するオープンなオムニモーダル世界基盤モデル「NVIDIA Cosmos 3 Nano」を、Hugging Face DiffusersとCPUオフロード技術を活用して12GBなどの比較的小容量なVRAMを持つローカルGPU環境で実行する具体的な手順を解説しています。

大きなモデルの重みをVRAMにすべて保持することが困難な課題に対し、モデルの重みをシステムのRAM（メインメモリ）に保存し、計算に必要なトランスフォーマーブロック単位でGPUへ動的に転送・実行するストリーミングアダプターの仕組みが紹介されています。これにより、システムRAMをバッキングストアとして活用しながら、CUDAで効率的に行列計算やアテンション処理を行うことが可能です。

具体的な導入手順としては、まずLinux環境でPython 3.12やCUDA対応PyTorchが稼働する前提のもと、GitHubから「Cosmos-Framework」をクローンし、スタンドアロンのオフloadingパッケージをインストールします。その後、Hugging FaceのリポジトリID（`nvidia/Cosmos3-Nano`）を指定してパイプラインを構築します。

テキストからの動画生成（Text-to-Video）においては、解像度やフレームレート、推論ステップ数などを辞書型引数で設定し、生成されたフレームをMP4形式として保存するコードが示されています。また、テキストだけでなく、画像を入力条件にするImage-to-Video、既存動画を活用するVideo-to-Video、音声生成を同時に行う設定（`enable_sound=True`）、さらにロボットの行動ポリシーを出力するアクション生成やコントロールガイド付き生成など、多彩なモダリティに対応した実装例が詳細に解説されています。

さらに、メモリ使用量をさらに削減する手法として、FP8チェックポイントを活用する方法が説明されています。`revision="fp8"`を指定してモデルを読み込み、NVIDIA Model Optimizerを含む拡張パッケージを追加インストールすることで、W8A16（8bit重み・16bit活性化）などの量子化ポリシーを適用し、精度を維持しながらVRAM消費量を抑えた実行が可能になります。

記事の後半では、GeForce RTX 5070（12GB）、RTX 5080（16GB）、RTX 4090（24GB）、RTX 5090（32GB）といったコンシューマー向けGPUにおける、解像度（240p、480p、720p）ごとのパイプラインレイテンシやピークデバイスメモリの計測結果（ベンチマークデータ）が比較提示されており、自身のハードウェア環境に合わせた解像度選択や動作検証の目安として活用できるようになっています。新人エンジニアにとっても、大規模なAIモデルを限られたローカルハードウェアリソースで動かすためのメモリ管理手法や、Hugging Face Diffusersを通じた実践的なパイプライン構築を学ぶうえで非常に有益な内容となっています。

引用元: https://developer.nvidia.com/blog/how-to-run-nvidia-cosmos-3-on-local-ai-devices-using-hugging-face-diffusers/


- [Introducing Search for Agents](https://blog.cloudflare.com/search-for-agents/)  


Cloudflareは、AIエージェント向けにWebサイトの検索エンドポイントをネットワークレベルで自動構築する新機能「Search for Agents」を発表しました。これまでAI Searchを利用してサイト内検索を導入するには、初期設定やインフラ構築、ドメインへのエンドポイント統合などを手動で行う必要がありましたが、新機能ではCloudflareダッシュボード上のトグルを有効にするだけで、自動的にAI Searchインスタンスが作成され、コンテンツのクロールとインデックス作成が開始されます。

新機能の大きな特徴は、AIエージェントに対する「発見性（Discoverability）」の高さにあります。機能を有効にすると、サイトのすべてのHTMLページの`<head>`内や、Markdown for Agentsと連携している場合のYAMLフロントマターに、検索APIの場所やメソッド、使用方法を記述したメタデータが自動的に追加されます。これにより、エージェントは個別のページを網羅的にクロールすることなく、メタデータを読み取って自律的に検索エンドポイントを特定し、キーワードや自然言語によるクエリを実行できるようになります。

検索結果は、AIモデルによる勝手な要約ではなく、Markdown形式の取得済みコンテンツとして返されるため、エージェント側が保持しているAIモデルとの対話において正確な情報を素早く活用できます。また、検索リクエストには、サーバーの状態を変更せずに安全かつべき等に検索条件を送信できるIETF提案標準の新しいHTTPメソッド「QUERY」がネイティブでサポートされており、プレーンテキストまたはJSONのリクエストボディを用いた柔軟なクエリ送信が可能です。

「Search for Agents」は無料プランを含むすべてのCloudflareユーザーが利用可能で、ダッシュボードの「Quick Actions」から簡単に有効化できます。デフォルト設定でのインスタンス作成後も、再ランキングの有効化やキャッシュ設定などのカスタマイズが可能であり、パブリックREST APIやMCP（Model Context Protocol）エンドポイント、Workersバインディングなど、従来のAI Searchが持つ豊富な機能とも連携します。新人エンジニアにとっても、AIエージェントとWebインフラストラクチャがどのように連携し、APIを自己発見させる仕組みが構築されているのかを学ぶ上で非常に価値の高いアップデートとなっています。

引用元: https://blog.cloudflare.com/search-for-agents/
